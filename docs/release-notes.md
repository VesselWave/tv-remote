First public preview release, **v0.1**.

A tiny local-network Android remote for LG webOS TVs. No account, cloud, ads, or analytics.

D-pad and touchpad · dedicated scroll strip · inputs and apps · keyboard · media controls · Wake-on-LAN and Bluetooth LE wake.

**Install:** download the `.apk` below on an Android 9+ phone and allow installation from your browser or file manager. Join the same LAN as the TV, select it, and accept the on-TV pairing prompt (which may say “LG Mobile”).

**Verify:** the `.sha256` file contains the APK checksum; `.certificate.txt` contains the signing certificate fingerprint. Keep using releases from this repository to preserve the update signature.

**Compatibility:** tested with LG 65UT7570PUB / webOS 24 and Pixel 7. Wake features require the TV's Mobile TV On / Turn on via Wi-Fi setting and supported hardware. Other TV models and firmware versions may differ.

See the [README](https://github.com/VesselWave/tv-remote#readme) for setup and troubleshooting, and [CHANGELOG](https://github.com/VesselWave/tv-remote/blob/main/CHANGELOG.md) for version history.
