**TV Remote 0.2** is rebuilt with Expo and React Native, keeping the same remote layout and local protocol engine.

**New:** icons on the remote's buttons (inputs, mute, apps, keyboard, channel, Buttons/Touchpad, back, home and TV settings), Material menus for setup, settings, apps, inputs and keyboard, searchable apps, and a larger touchpad.

**Install:** download `tv-remote-v0.2.apk` below, or from [tvremote.vwave.me](https://tvremote.vwave.me), on an Android 7+ phone (arm64). Allow installation from your browser or file manager. It updates 0.1 in place and keeps your pairing. For a first install, join the same LAN as the TV, select it, and accept the on-TV pairing prompt (which may say “LG Mobile”).

**Verify:** the `.sha256` file contains the APK checksum; `.certificate.txt` contains the signing certificate fingerprint, unchanged from 0.1. Keep using releases from this repository to preserve the update signature.

**Compatibility:** tested with LG 65UT7570PUB / webOS 24 and Pixel 7. Wake features require the TV's Mobile TV On / Turn on via Wi-Fi setting and supported hardware. Other TV models and firmware versions may differ.

See the [README](https://github.com/VesselWave/tv-remote#readme) for setup and troubleshooting, and [CHANGELOG](https://github.com/VesselWave/tv-remote/blob/main/CHANGELOG.md) for version history.
