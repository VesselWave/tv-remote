TV Remote is now Wave Remote. The remote itself is unchanged from 0.2.

- New name, and the download site moved to [remote.vwave.me](https://remote.vwave.me)
- The package ID is now `me.vwave.remote`, so this version installs alongside TV Remote instead of updating it. Pair your TV again, then uninstall the old app.

To check the download: `sha256sum --check wave-remote-v0.3.apk.sha256`.

Tested with an LG 65UT7570PUB (webOS 24) and a Pixel 7. Setup and troubleshooting are in the [README](https://github.com/VesselWave/wave-remote#readme). Not affiliated with LG.
