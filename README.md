## Setup

1. Install the APK on an Android 7+ phone.
2. Connect to the same network as the TV.
3. Open the app, pick your TV and accept the prompt on the TV.

To turn the TV on from the app, enable **Mobile TV On** in the TV's settings. Stuck? See [troubleshooting](docs/TROUBLESHOOTING.md).

## Building

Needs Bun, JDK 17+ and the Android SDK.

```sh
bun install
./build.sh debug
```
